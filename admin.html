    Payments

    Razorpay Payment Details

    User app mein "Pay Now" button click karte hi Razorpay ka checkout popup khulega (Cards, UPI, Netbanking, Wallets sab support karta hai). Apna Razorpay Key ID dashboard.razorpay.com/app/keys se le sakte hain.

    Note: Ye sirf Key ID (public) hai, isse payment collect hoti hai lekin verification client-side hoti hai — isliye har payment request ko neeche list mein Razorpay Dashboard se match karke hi Approve karein.

    Payment QR Code

    User app mein ye QR code "Pay Now" button ke saath dikhega, jisse user seedha apne UPI app se scan karke bhi pay kar sakta hai.

    Abhi tak koi QR code upload nahi hua hai.
